## Planned shape

Scarab is Kubernetes-only by design ([ADR-0005](/scarab-ci/tech/adr/0005-tenancy-and-k8s-only/)),
so a Helm chart is the intended install path for a real cluster:

- A published chart (chart repo or OCI registry) with a versioned `values.yaml`.
- Wiring for the durability substrate (Postgres) and the blob/object store.
- Namespace-per-run tenancy and the hardened step baseline
  ([ADR-0039](/scarab-ci/tech/adr/0039-privileged-images/)).

Until then, use [Run locally](/scarab-ci/get-started/run-locally/) to exercise the system.
