## The model, in brief

A Scarab pipeline is a **flat recursive DAG** (`Pipeline → Step`)
([ADR-0006](/scarab-ci/tech/adr/0006-pipeline-ontology/)). The real DSL is a **typed IR**; YAML is a
frontend and **CEL** provides expressions ([ADR-0009](/scarab-ci/tech/adr/0009-dsl-ir-yaml-cel/)).

- **`invoke`** is reuse — compile-time inlining of a library pipeline into the caller's DAG
  ([ADR-0038](/scarab-ci/tech/adr/0038-invoke-and-local-reuse/)).
- **`matrix`** is a modifier that fans a step out over a set of inputs.
- A **step** is an OCI image plus a contract ([ADR-0008](/scarab-ci/tech/adr/0008-step-contract/)).

Start from [Run locally](/scarab-ci/get-started/run-locally/) to submit your first pipeline.
