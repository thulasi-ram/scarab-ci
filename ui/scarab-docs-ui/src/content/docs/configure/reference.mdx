## Server configuration

`scarab-server` is configured from the environment (see `.env.local.example` and the `Justfile`
`serve` recipe). The core knobs today:

| Variable | Purpose |
|---|---|
| `SCARAB_DATABASE_URL` | Postgres connection — the durability substrate ([ADR-0003](/scarab-ci/tech/adr/0003-durability-substrate-postgres/)). |
| `SCARAB_S3_BUCKET`, `SCARAB_S3_ENDPOINT`, `SCARAB_S3_ACCESS_KEY`, `SCARAB_S3_SECRET_KEY`, `SCARAB_S3_REGION` | Object store for logs/blobs. |
| `KUBECONFIG`, `SCARAB_NAMESPACE` | Target cluster and namespace for pod-per-step execution. |

## Secrets & Environments

Secret handling ([ADR-0014](/scarab-ci/tech/adr/0014-secrets/)) and admin-owned **Environments**
that bundle governance ([ADR-0037](/scarab-ci/tech/adr/0037-environment-governance/)) are the model
for scoped configuration; operator-facing docs land as those slices do.
