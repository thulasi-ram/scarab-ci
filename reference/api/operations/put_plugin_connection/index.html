Bind a plugin connection's destination and credential (ADR-0072 §5)

PUT
/v1/orgs/{org}/plugins/{name}/connections/{slot}

The credential is written through to the secret store under a fresh server-minted key and is never readable back; the previous binding’s credential is deleted once the new binding is stored. A response stream the plugin has open on the old binding is cut within seconds.
